# 별모도로

## 무엇을 하는 서비스인가

집중 25분과 휴식 5분을 한 세트로 도는 뽀모도로(포커스) 타이머입니다. 휴식까지 끝까지 마친 세트만 밤하늘에 별로 뜨고, 중간에 그만둔 세트는 별이 되지 않습니다. 쌓인 별과 세트 수는 9:16 카드 그림으로 만들어 컴퓨터에 내려받을 수 있습니다.

- 끝까지 마친 세트 수(누적 세트 수)와 총 집중 시간(마친 세트 × 25분)을 보여 줍니다.
- 다른 탭에 다녀오거나 탭을 닫았다 다시 열어도 남은 시간이 이어지고, 그사이 세트 시간이 다 지났으면 한 세트로 셉니다.
- 컴퓨터 브라우저에서 쓰는 웹 서비스입니다.

## 누구를 위한 것인가

퇴근 후 저녁에 공부 같은 자기계발에 집중하는 직장인, 그중에서도 이미 뽀모도로(포커스) 타이머를 쓰고 있는 사람을 위한 서비스입니다.

- 세트를 반복해도 한 세트가 지나면 그냥 끝나서 재미를 느끼기 어려운 사람
- 혼자 쓰고 끝내지 않고, 쌓인 결과를 그림으로 남겨 다른 사람에게 보여 주고 싶은 사람

## 어떻게 쓰나

1. 첫 화면인 **타이머** 탭에서 **?** 를 누르면 뽀모도로 타이머 설명이 열립니다.
2. **시작**을 누르면 원형 타이머가 줄어들며 집중 25분이 시작되고, 끝나면 누르지 않아도 휴식 5분이 이어집니다. 세트 동안에는 화면이 저절로 꺼지지 않고, 집중이 끝날 때와 세트가 끝날 때 종소리가 납니다.
3. 집중·휴식 중에 **그만하기**를 누르면 "이번 세트는 별이 되지 않아요" 확인 창이 뜹니다. 창에서 **그만하기**를 누르면 그 세트는 별이 되지 않고 대기로 돌아가고, **계속하기**를 누르면 하던 집중·휴식으로 돌아갑니다.
4. 휴식까지 끝나면 저절로 **밤하늘** 탭으로 넘어가 별똥별이 떨어지고 밤하늘에 별이 더해집니다. 하늘 아래에 누적 세트 수와 총 집중 시간이 보입니다.
5. **다음 세트 시작**을 누르면 타이머 화면으로 가면서 바로 집중 25분이 시작됩니다. 세트가 진행 중일 때 밤하늘 탭에 오면 그 자리에 **집중 중 · 12:30 남음**(휴식 중이면 **휴식 중 · 04:30 남음**) 단추가 보이고, 누르면 진행 중인 타이머로 돌아갑니다.
6. **카드 만들기**를 누르면 쌓인 별과 세트 수가 담긴 9:16 카드 미리보기가 열립니다. 마친 세트가 하나도 없으면 누를 수 없습니다.
7. **이미지 저장**을 누르면 카드가 1080×1920 크기의 PNG(그림 파일 형식) 파일로 내려받아집니다. **←**를 누르면 밤하늘로 돌아갑니다.

위쪽의 **타이머** · **밤하늘** 탭을 눌러 언제든 두 화면을 오갈 수 있습니다.
