# 목표 기록 구조 (PRD 6판)

- 2026-10-31 정함 · 주말 6판 작업 1단계
- 서버 표 만들기: [supabase/goal_log.sql](../supabase/goal_log.sql)
- PRD 6판 "구현 필수 조건"을 따릅니다. 목표 표의 한 줄은 한 기간입니다.
  - 칸: 별자리 · 기간 종류 · 기간 시작일 · 목표 세트 수 · 이번 기간 세트 수 · 완성 여부

## 어디에 두나

| 값 | 그냥 주소 | 테스터 링크 (…/?t=07) | 시연 링크 (…/?demo=1) |
|---|---|---|---|
| 누적 세트 수 | 브라우저 | 서버 `progress` + 브라우저 사본 (지금과 같음) | 서버 `progress` 의 '0' 줄 (지금과 같음) |
| 지금 목표와 이번 기간 세트 수 | 브라우저 | 서버 `goal_log` + 브라우저 사본 | 서버 `goal_log` 의 '0' 줄 |
| 지난 별자리 목록 | 브라우저 | 서버 `goal_log` 에서 읽음 | 서버 `goal_log` 의 '0' 줄 |
| 진행 중 세트의 시작 시각과 그 세트의 목표 | 브라우저 | 브라우저 | 브라우저에 남기지 않음 (지금과 같음) |

- 서버에 저장하지 못하면 브라우저에 "아직 못 올림"을 남겼다가 다음에 올립니다. 지금 누적 세트 수를 다루는 방식과 같습니다.
- 시연 줄 '0' 은 실제 기록과 섞이지 않습니다. 판정할 때는 빼고 셉니다.

## goal_log 표의 칸

| 칸 | 뜻 | 예 |
|---|---|---|
| id | 줄 번호 (저절로) | 12 |
| tester | 테스터 번호, 시연은 '0' | '07' |
| constellation | 별자리 (constellations.py 의 key) | 'orion' |
| period | 기간 종류 | '하루' · '한 주' |
| period_start | 기간 시작일 (한국 시각) | 하루는 그날, 한 주는 그 주 월요일 |
| target | 목표 세트 수 | 3 |
| set_count | 이번 기간 세트 수 | 1 |
| completed | 완성 여부 (set_count ≥ target 이면 저절로 참) | true |
| source | 정한 방법 | '추천' · '이어서' · '고름' |
| created_at | 만든 시각 (저절로) | |

- 같은 사람 · 같은 기간에는 한 줄만 둡니다.
- 앱 키로는 지울 수 없습니다.
- 사람 칸 이름은 기존 `progress` · `event_log` 와 같은 `tester` 로 둡니다. 11/3 구글 로그인 때 세 표를 함께 계정 번호로 바꿉니다.

## 규칙

1. **기간 계산** (한국 시각)
   - 하루: 그날 자정까지
   - 한 주: 달력 한 주(월요일~일요일)
2. **지금 목표 찾기**
   - 기간이 오늘을 품는 줄입니다. 하루는 시작일이 오늘인 줄, 한 주는 시작일이 이번 주 월요일인 줄입니다.
   - 여럿이면 번호가 가장 큰 줄을 씁니다.
3. **없으면 저절로 정하기** (처음 들어왔을 때, 기간이 끝났을 때)
   - 예전 줄이 없으면 오리온자리 하루 3세트로 정합니다(정한 방법 '추천').
   - 예전 줄이 있으면 가장 최근 줄과 같은 별자리 · 목표로 정합니다('이어서').
   - 새 줄을 만들어 둡니다.
   - 화면1의 "처음이라 추천 목표로 정했어요"는 지금 줄이 '추천'일 때만 보입니다.
4. **목표 바꾸기** (이번 기간 세트 수가 0일 때만)
   - 같은 줄을 고칩니다. 바뀌는 칸은 별자리 · 기간 종류 · 기간 시작일 · 목표 세트 수이고, 정한 방법은 '고름'이 됩니다.
   - 세트를 하지 않은 목표가 여러 줄로 쌓이지 않습니다.
5. **세트 완료**
   - 세트를 시작할 때 그 목표 줄 번호를 기억해 둡니다.
   - 끝나면 그 줄의 세트 수에 1을 더하고, 누적 세트 수에도 1을 더합니다.
   - 자정이나 일요일 밤을 넘겨 끝나도 시작한 기간에 들어갑니다(PRD 6판).
6. **지난 별자리**
   - 지금 기간보다 앞서고 세트 수가 1 이상인 줄을 최근 것부터 보여 줍니다.
   - 세트 0개 기간은 목록과 판정에서 뺍니다.

## 판정 지표 셈
