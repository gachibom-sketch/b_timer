# 별모도로 토스판 화면 시안 (밝은 바탕)

토스 앱 미니앱(앱인토스)으로 낼 때의 화면 시안입니다.
- **왜 밝은가**: 앱인토스는 라이트 모드(밝은 화면)만 받습니다([점검 문서](../../앱인토스%20출시%20점검.md)). 그래서 바탕은 밝게 하고, 밤하늘 칸·별자리 그림·카드 그림만 어둡게 두었습니다.
- **1라운드 웹판**: [위 폴더](../README.md)의 검정 바탕 시안을 그대로 씁니다.

- **폴더마다**: 화면 그림 `screen.png`(2배 크기, 가로 780), 화면 코드 `code.html`, 스티치 화면 번호 `stitch.json`

## 웹판 시안과 달라진 점
- **맨 위**: 토스가 붙여 주는 내비게이션 바 자리입니다(‹ 뒤로가기 · 로고 · 별모도로 · ⋯ · ✕).
  - 우리 제목, 위쪽 탭, 화면 3 (카드 미리보기)의 "←"는 없앴습니다. 뒤로가기 단추가 겹치면 검수에서 걸립니다.
- **맨 아래**: 토스식 떠 있는 탭바(타이머 · 밤하늘)입니다. 화면 0 (목표 설정)과 화면 3 (카드 미리보기)에는 없습니다.
- **단추**: 노란 주 단추와 회색 보조 단추, 둥근 모서리입니다.
- **강조 글자**: 흰 바탕에서는 노란 글자가 보이지 않습니다. 그래서 "2/3", "완성"은 노란 형광펜 바탕 위 검은 글자로 했습니다.
- **카드 하단 주소 자리**: "토스에서 ‘별모도로’ 검색" — 점검 문서 제안 1대로 2026-10-29 에 정했습니다.
- **시연 모드 칸**: 토스판에서는 빼기로 해서 시안을 만들지 않았습니다.
- **앱 로고**: 600×600 로고는 아직 없습니다. 이동 막대의 로고는 화면마다 조금 다르고, 자리만 잡은 그림입니다.
