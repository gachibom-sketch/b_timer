# 토스판 디자인 규칙 — 밝은 바탕 + 밤하늘 칸만 어둡게

앱인토스(토스 앱 미니앱)는 라이트 모드(밝은 화면)만 받습니다([점검 문서](../../앱인토스%20출시%20점검.md)).
- 화면 바탕과 글자, 단추는 밝게 합니다.
- 밤하늘 그림만 어둡게 둡니다.
- 1라운드 웹판은 [검정 바탕 규칙](../DESIGN.md)(Nocturne Focus)을 그대로 씁니다.

## 색

| 쓰임 | 색 |
|---|---|
| 화면 바탕 | #FFFFFF |
| 회색 면 (보조 단추, 도움말 원) | #F2F4F6 |
| 본문 글자 | #191F28 |
| 보조 글자 | #6B7684 |
| 흐린 글자 (캡션, 안 고른 탭) | #8B95A1 |
| 가는 선, 카드 테두리 | #E5E8EB |
| 주 단추 노랑 | #FFE14D |
| 강조 형광펜, 알약 꼬리표 바탕 | #FFF0A0 |
| 알약 꼬리표 글자 | #7A5C00 |
| 고른 카드 테두리 / 바탕 | #FFD000 / #FFFBE6 |

### 밤하늘 칸 (어두운 곳은 여기만)
- 대상: 화면 2 (밤하늘)의 하늘 칸, 별자리 작은 그림, 화면 3 (카드 미리보기)의 카드 그림
- 바탕: 남색 세로 그라데이션, 위 #0E1430 → 아래 #1C2650
- 별: 흰색에 은은한 빛
- 별자리 선과 하늘 안 강조: 달빛 노랑 #FFEF4D
- 흰 바탕에서는 노란 글자가 보이지 않습니다. 그래서 하늘 밖의 강조 글자("2/3", "완성")는 형광펜 바탕 #FFF0A0 위에 검은 글자 #191F28 로 씁니다.

## 원형 타이머 (화면 1 (타이머))
- 꽉 찬 원입니다. 한 바퀴가 한 세트입니다.
- 휴식 5분: 12시에서 시계 방향으로 2시까지의 60° 조각, 남색 #1C2650 에 노란 #FFEF4D 빗금
- 집중 25분: 나머지 300° 조각, 꽉 찬 노랑 #FFE14D
- 이미 지난 부분: #F2F4F6, 바깥 고리: #D1D6DB 가는 선, 눈금과 가운데 점: #191F28

## 모양
- 모서리: 밤하늘 칸·큰 카드·확인 창 20px, 단추·목록 줄 16px, 작은 그림 12px, 알약과 탭바는 완전히 둥글게
- 주 단추: 가로 꽉, 높이 56px, #FFE14D 바탕에 #191F28 굵은 17px 글자, 테두리 없음
- 보조 단추: #F2F4F6 바탕에 #333D4B 글자, 테두리 없음
- 고른 카드: 테두리 2px #FFD000, 바탕 #FFFBE6, 오른쪽에 노란 체크 원
- 확인 창: 흰 카드, 뒤 화면은 rgba(0,0,0,0.4)로 어둡게, 단추 두 개를 나란히 (보조 · 주)
- 검정 바탕 규칙의 "+" 모서리 표시, 십자선, 각진 모서리는 쓰지 않습니다.

## 글꼴
- Noto Sans KR 하나만 씁니다. 한글 글자 사이는 보통 간격입니다.
- 타이머 숫자는 시안에서 좁은 글꼴로 나온 화면이 있지만, 만들 때는 Noto Sans KR 숫자(폭이 같은 숫자)로 합니다.

## 토스가 붙이는 부분
- **맨 위 이동 막대**: 토스가 자동으로 붙이는 내비게이션 바입니다(약 54px).
  - 왼쪽: ‹ 뒤로가기, 로고, "별모도로" / 오른쪽: ⋯, ✕
  - 우리 화면에는 제목, 위쪽 탭, 따로 만든 뒤로가기 단추를 두지 않습니다. 뒤로가기 단추가 겹치면 검수에서 걸립니다.
- **맨 아래 탭바**: 토스식 떠 있는 탭바 — "타이머 · 밤하늘" 두 개
  - 모양: 흰 알약, 높이 64px, 아래 12px·양옆 16px 띄움, 그림자 0 4px 16px rgba(0,0,0,0.08)
  - 고른 탭: #191F28 굵게 / 안 고른 탭: #8B95A1
  - 화면 0 (목표 설정)과 화면 3 (카드 미리보기)에는 두지 않습니다.
- **앱 로고**: 600×600 PNG 각진 정사각형에 배경색이 있어야 합니다. 아직 만들지 않았고, 시안의 로고는 자리만 잡은 그림입니다.
