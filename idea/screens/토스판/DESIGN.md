# 토스판 디자인 규칙 — 밝은 바탕 + 밤하늘 칸과 남색 조각만 어둡게

앱인토스(토스 앱 미니앱)는 라이트 모드(밝은 화면)만 받습니다([점검 문서](../../앱인토스%20출시%20점검.md)).
- 화면 바탕과 글자는 밝게 합니다.
- 어두운 곳은 두 가지뿐입니다.
  - 밤하늘 그림
  - 흰 바탕에서 눈에 띄어야 하는 "남색 조각": 주 단추 · 강조 꼬리표 · 고른 표시 · 타이머의 남은 시간 조각(2026-10-31 부터 원판 바탕은 흰색)
- 노랑은 흰 바탕에 직접 칠하지 않습니다. 흰색과 1.30:1 이라 잘 안 보입니다. 노랑은 남색 조각이나 밤하늘 위에서만 씁니다.
- 2026-10-30 hae님 결정: 색 조합 A안 "밤하늘 조각" + 휴식 조각 다안 "초저녁 하늘". 비교와 근거는 [토스판 색 조합](../../토스판%20색%20조합.md)에 있습니다.
- 1라운드 웹판도 2026-10-31부터 이 밝은 규칙의 색·모양을 씁니다(토스가 붙이는 부분 빼고). [검정 바탕 규칙](../DESIGN.md)(Nocturne Focus)은 기록으로 둡니다.
  - 웹판에서 쓰는 곳: .streamlit/config.toml(색), app.py 의 APP_STYLE(단추·꼬리표·창), timer_parts.py(원형 타이머), goal_parts.py(화면 0 카드), sky_parts.py(지난 별자리 목록)
  - 웹판은 토스 이동 막대·로고·떠 있는 탭바를 만들지 않고, Streamlit 맨 위 탭(목표 설정 · 타이머 · 밤하늘)과 "별모도로" 제목을 그대로 둡니다.

## 원형 타이머 (화면 1 (타이머))
2026-10-31 hae님 결정: "남은 시간만 색" + 가안 "밤하늘 두 톤". 웹판과 나중에 만들 토스판이 같은 원판을 씁니다.
- 꽉 찬 원입니다. 한 바퀴가 한 세트입니다.
- 원판 바탕과 지나간 부분: 흰색 #FFFFFF. 색이 남은 시간이고, 하얀 곳이 지나간 시간입니다.
- 남은 집중 25분: 2시부터 시계 방향으로 12시까지의 300° 조각, 짙은 남색 #1C2650 (주 단추와 같은 색)
- 남은 휴식 5분: 12시부터 2시까지의 60° 조각, 밝은 남색 #6C7ECB. 빗금 · 줄무늬 · 점은 쓰지 않습니다.
  - 10/30 의 휴식 "다안" #576CC4 는 지나간 부분(남색)과의 대비 때문에 고른 색이었습니다. 지나간 부분이 흰색이 되어, 흰색·남은 집중 둘 다와 대비가 가장 큰 #6C7ECB 로 바꿨습니다.
- 노랑은 원판에 쓰지 않습니다(흰색과 1.30:1). 노랑은 남색 위(단추 글자 · 꼬리표 · 밤하늘 별)에서만 씁니다.
- 줄어드는 방향: 실제 앱(timer_parts.py)과 같습니다.
  - 남은 부분은 12시에서 시계 방향으로 지금 위치까지입니다. 시간이 지나면 끝이 12시 쪽으로 돌아옵니다.
  - 집중이 다 지나면 휴식 조각이 12시 쪽으로 줄어듭니다.
- 테두리와 눈금 12개: 옅은 회색 #8B95A1 가는 선. 원 모양과 남은 비율을 가늠하는 기준입니다(흰색과 3.04:1).
- 가운데: 흰 원에 #191F28 테두리와 점
- 범례: 대기 때만 원 아래에 "● 집중 25분 · ● 휴식 5분"(점은 각 조각 색, 글자 #6B7684). 밝은 휴식 조각을 "지나간 시간"으로 읽지 않게 합니다. 시연 모드는 세트 길이대로 "집중 1분 · 휴식 12초".
- 세트 중 꼬리표 "● 집중 중" / "● 휴식 중"은 그대로 남색 바탕 + 노란 글자입니다.
- 대비 (그림은 3:1 이상)
  - 남은 집중 ↔ 흰색: 14.56:1
  - 남은 휴식 ↔ 흰색: 3.83:1
  - 남은 집중 ↔ 남은 휴식: 3.80:1 (색약 흉내 적색약 3.93 · 녹색약 3.74 · 청색약 3.84, Machado 2009 가장 심한 단계)
- 웹판·토스판 시안 1A·1B 그림은 예전 원판(남색 바탕 + 노란 집중)으로 남아 있습니다. 원판은 이 절을 따릅니다.
- 다른 후보(지금 노랑 + 남색 테두리 · 노을 주황 + 남색 · 토스 파랑 + 남색)와 비교한 숫자:

## 모양
- 모서리: 밤하늘 칸 · 큰 카드 · 확인 창 20px, 단추 · 목록 줄 16px, 작은 그림 12px, 알약과 탭바는 완전히 둥글게
- 주 단추: 가로 꽉, 높이 56px, #1C2650 바탕에 #FFE14D 굵은 17px 글자, 테두리 없음 (누를 때 #0E1430)
- 보조 단추: #F2F4F6 바탕에 #333D4B 글자, 테두리 없음
- 강조 꼬리표("집중 중", "처음이라면 추천", "2/3세트", "완성"): #1C2650 바탕에 #FFE14D 글자. 점이 있으면 점도 #FFE14D
- 고른 카드: 테두리 2px #1C2650, 바탕 #FFFFFF, 오른쪽에 남색 체크 원 #1C2650 + 노란 체크 #FFE14D
- 확인 창
  - 흰 카드이고, 뒤 화면은 rgba(0,0,0,0.4)로 어둡게 합니다.
  - 단추 두 개를 나란히 둡니다 (보조 · 주).
  - 그림표는 남색 원 #1C2650 안의 노란 그림 #FFE14D 입니다.
- 검정 바탕 규칙의 "+" 모서리 표시, 십자선, 각진 모서리는 쓰지 않습니다.

## 글꼴
- Noto Sans KR 하나만 씁니다. 한글 글자 사이는 보통 간격입니다.
- 타이머 숫자는 시안에서 좁은 글꼴로 나온 화면이 있지만, 만들 때는 Noto Sans KR 숫자(폭이 같은 숫자)로 합니다.

## 토스가 붙이는 부분
- **맨 위 이동 막대**: 토스가 자동으로 붙이는 내비게이션 바입니다(약 54px).
  - 왼쪽: ‹ 뒤로가기, 로고, "별모도로" / 오른쪽: ⋯, ✕
  - 우리 화면에는 제목, 위쪽 탭, 따로 만든 뒤로가기 단추를 두지 않습니다. 뒤로가기 단추가 겹치면 검수에서 걸립니다.
- **맨 아래 탭바**: 토스식 떠 있는 탭바 — "타이머 · 밤하늘" 두 개
  - 모양: 흰 알약, 높이 64px, 아래 12px · 양옆 16px 띄움, 그림자 0 4px 16px rgba(0,0,0,0.08)
  - 고른 탭: #191F28 굵게 / 안 고른 탭: #6B7684
  - 화면 0 (목표 설정)과 화면 3 (카드 미리보기)에는 두지 않습니다.
- **앱 로고**
  - 600×600 PNG 각진 정사각형에 배경색이 있어야 합니다.
  - 아직 만들지 않았고, 시안의 로고는 자리만 잡은 그림입니다.
  - 바탕색 후보는 둘이고, 로고를 만들 때 정합니다.
    - #576CC4: 10/30 의 휴식 조각 색(10/31 부터 휴식 조각은 #6C7ECB). 흰 화면 4.83:1 · 검정 화면 4.35:1 · 노란 별 3.71:1
    - #3D4FA8: 흰 화면 7.29:1 · 검정 화면 2.88:1 · 노란 별 5.60:1
