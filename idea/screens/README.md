# 별모도로 화면 시안 (구글 스티치)

구글 스티치 프로젝트 "별도로 밤하늘 화면 디자인"에서 만든 휴대폰 크기(가로 390) 화면 시안입니다. 서비스 이름은 2026-10-29 에 "별도로"에서 "별모도로"로 바뀌었습니다(스티치 프로젝트 이름은 그대로).

- 폴더마다 화면 그림 `screen.png`(2배 크기, 780×1768 — 2A 만 직접 내보낸 그림이라 390×844), 화면 코드 `code.html`, 스티치 화면 번호 `stitch.json` 이 있습니다.
- 원형 타이머 색: 집중 25분(300°) = 꽉 찬 노랑, 휴식 5분(60°) = 남색 바탕에 노란 빗금.
- 카드의 별은 화면2 와 같은 크기 규칙을 지킵니다(1세트 = 아주 작은 점 1개). 별이 적을 때 허전하지 않게 하는 것은 달빛 고리 같은 배경 장식으로 합니다.
- 1판 카드 맨 아래 "별도로"(바꾸기 전 이름) 밑에는 카드를 만든 날이 "2026.10.27 기준" 처럼 작은 회색 글자로 들어갑니다. 1판 시안의 이름은 고치지 않았습니다.
- 모든 화면은 같은 디자인 규칙 [DESIGN.md](DESIGN.md)(Nocturne Focus — 검정 바탕, 남색 판, 달빛 노랑 #FFEF4D)를 따릅니다.
- 토스 앱 미니앱(앱인토스)용 밝은 바탕 시안은 [토스판](토스판/README.md) 폴더에 따로 있습니다(2026-10-29). 1라운드 웹판은 이 폴더의 검정 바탕 시안을 그대로 씁니다.

## 4판 시안 (별자리 5개 중 고르기, 2026-10-29)
PRD 4판과 [별자리 규칙 보완판](../별모도로%20별자리%20MVP%20규칙_보완.md)의 화면입니다. 와이어프레임에 없는 화면이라 번호를 이어 붙였습니다.
예시 상황은 2E·2F·3D·3E 가 같습니다: 오늘(10/29)은 오리온자리(별 7개, 하루 3세트) · 10/27 백조자리 3/5세트 · 10/28 카시오페이아자리 완성.

- 다 켜진 별은 빛나는 별 모양, 차오르는 중인 별은 같은 모양을 작고 옅게, 아직 차오르지 않은 자리는 희미한 회색 점과 고리로 그립니다. 100%가 되면 노란 선이 별을 잇고, 넘긴 세트는 선 없는 작은 흰 점(덤 별)으로 별자리와 떨어진 자리에 뜹니다.
- 별마다 색을 조금씩 다르게 합니다(오리온자리 베텔게우스는 붉은 주황, 리겔은 푸르스름한 흰색).
- 카드 하단의 `byeolmodoro.streamlit.app` 은 예시 주소입니다. 10/30 배포 뒤 실제 주소로 바꿉니다.
- 글꼴은 Noto Sans KR 하나이고 한글 글자 사이는 보통 간격입니다(카드의 주소만 고정폭 글꼴).
- 2E·2F 의 code.html 에는 바탕으로 쓴 2B 의 설명 글(주석) "시연 모드"·"Chatbot" 이 남아 있지만, 실제 단추는 없습니다.
- 2026-10-30 첫 화면 C안: 처음 들어오면 추천 목표(오리온자리 하루 3세트)가 저절로 정해져 화면1 대기로 바로 가고, 기간이 끝나면 지난번 별자리로 저절로 이어집니다. 화면0은 화면1의 "목표 바꾸기"(이번 기간 0세트일 때만)로만 엽니다.
- 아직 시안이 없는 4판 화면: 화면1 대기의 진행 줄("오리온자리 · 0/3세트 · 오늘")과 "처음이라 추천 목표로 정했어요 · 목표 바꾸기"(밝은 바탕 모습은 [토스판 1A](토스판/1A_타이머_대기/screen.png)에 있음), 이번 기간 0세트일 때, 한 주 목표일 때, 시연 칸("세트 수": 0·절반·목표 직전·완성·덤 별 +3).
