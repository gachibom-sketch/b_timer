# 별도로 화면 시안 (구글 스티치)

구글 스티치 프로젝트 "별도로 밤하늘 화면 디자인"에서 만든 휴대폰 크기(가로 390) 화면 시안입니다.

- 폴더마다 화면 그림 `screen.png`(2배 크기, 780×1768 — 2A 만 직접 내보낸 그림이라 390×844), 화면 코드 `code.html`, 스티치 화면 번호 `stitch.json` 이 있습니다.
- 원형 타이머 색: 집중 25분(300°) = 꽉 찬 노랑, 휴식 5분(60°) = 남색 바탕에 노란 빗금.
- 카드의 별은 화면2 와 같은 크기 규칙을 지킵니다(1세트 = 아주 작은 점 1개). 별이 적을 때 허전하지 않게 하는 것은 달빛 고리 같은 배경 장식으로 합니다.
- 카드 맨 아래 "별도로" 밑에는 카드를 만든 날이 "2026.10.27 기준" 처럼 작은 회색 글자로 들어갑니다.
- 모든 화면은 같은 디자인 규칙 [DESIGN.md](DESIGN.md)(Nocturne Focus — 검정 바탕, 남색 판, 달빛 노랑 #FFEF4D)를 따릅니다.

## 2판 시안 (목표 별자리, 2026-10-29)
PRD 2판의 화면입니다. 와이어프레임에 없는 화면이라 번호를 이어 붙였습니다. 예시는 모두 카시오페이아자리(오늘 5세트, W 모양 별 5개)입니다.

| 번호 | 화면 | 상태 | 폴더 |
|---|---|---|---|
| 0A | 화면0 목표 설정 | 별자리 3개 중 고르기 · 삼각형자리가 미리 골라져 있음 | [0A_목표_설정](0A_목표_설정/screen.png) |
| 2E | 화면2 밤하늘 | 카시오페이아자리 3/5 채우는 중 · 왼쪽 위에 전에 완성한 삼각형자리 | [2E_밤하늘_별자리_진행중](2E_밤하늘_별자리_진행중/screen.png) |
| 2F | 화면2 밤하늘 | 카시오페이아자리 완성 · 단추가 "다음 목표 고르기"로 바뀜 | [2F_밤하늘_별자리_완성](2F_밤하늘_별자리_완성/screen.png) |
| 3D | 화면3 카드 미리보기 | 진행 카드 (3/5) | [3D_카드_별자리_진행](3D_카드_별자리_진행/screen.png) |
| 3E | 화면3 카드 미리보기 | 완성 카드 | [3E_카드_별자리_완성](3E_카드_별자리_완성/screen.png) |

- 켜진 별은 노란 별 모양, 아직 안 켜진 별은 희미한 회색 점과 고리입니다. 목표를 채우면 노란 선이 별을 차례로 잇습니다.
- 글꼴은 Noto Sans KR 하나이고 한글 글자 사이는 보통 간격입니다. 1판 시안의 넓은 글자 사이·좁은 숫자 글꼴은 쓰지 않습니다.
- 2E·2F 의 code.html 에는 바탕으로 쓴 2B 의 설명 글(주석) "시연 모드"·"Chatbot" 이 남아 있지만, 실제 단추는 없습니다.
- 아직 시안이 없는 2판 화면: 화면1 대기의 목표 진행 표시("카시오페이아자리 3/5 · 오늘")와 "목표 바꾸기", 켜진 별이 0개일 때, 기간이 끝난 미완성 별자리, 시연 칸("켜진 별 수").

## 만들지 않은 화면
- 2-C 별이 합쳐지는 순간: 앱에서 움직임으로 이미 만들었습니다(sky_parts.py).
- 3-B 공유 안내 창, 3-C 캡처 안내 카드: 1라운드는 컴퓨터 전용이라 쓰지 않습니다.
