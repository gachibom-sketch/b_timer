# 별도로 화면 시안 (구글 스티치)

구글 스티치 프로젝트 "별도로 밤하늘 화면 디자인"에서 만든 휴대폰 크기(가로 390) 화면 시안입니다.

- 폴더마다 화면 그림 `screen.png`(2배 크기, 780×1768 — 2A 만 직접 내보낸 그림이라 390×844), 화면 코드 `code.html`, 스티치 화면 번호 `stitch.json` 이 있습니다.
- 원형 타이머 색: 집중 25분(300°) = 꽉 찬 노랑, 휴식 5분(60°) = 남색 바탕에 노란 빗금.
- 모든 화면은 같은 디자인 규칙 [DESIGN.md](DESIGN.md)(Nocturne Focus — 검정 바탕, 남색 판, 달빛 노랑 #FFEF4D)를 따릅니다.

## 만들지 않은 화면
- 2-C 별이 합쳐지는 순간: 앱에서 움직임으로 이미 만들었습니다(sky_parts.py).
- 3-B 공유 안내 창, 3-C 캡처 안내 카드: 1라운드는 컴퓨터 전용이라 쓰지 않습니다.

## _보관
예전 판을 지우지 않고 모아 둔 곳입니다.
- `1E_타이머_대기_23세트_처음판(물음표없음)`: 처음 내보낸 타이머 화면. "?" 단추가 없어 새로 만든 1E 로 바꿨습니다.
- `2A_밤하늘_0세트_컴퓨터판`: 앱 크기로 정하기 전에 만든 컴퓨터 화면 크기(1280×900) 시안.
