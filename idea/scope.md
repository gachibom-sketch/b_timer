## 1라운드 포함 — 핵심 기능 3개

1. **뽀모도로 타이머** — 화면1
   집중 25분 + 휴식 5분 한 세트, 길이는 고정. 집중이 끝나면 휴식이 자동으로 시작되고, 휴식이 끝나면 세트 완료. 일시정지 없이 "그만하기"만 있고, 누르면 "이번 세트는 별이 되지 않아요" 확인 창을 거쳐 세트를 인정하지 않음(휴식 건너뛰기 포함). 남은 시간은 시작 시각 기준으로 계산해서, 다른 탭에 있거나 화면이 꺼졌다 돌아와도 맞게 보임. 소리는 화면이 켜져 있을 때만, 집중이 끝날 때와 세트가 끝날 때 남. 대기 상태에서는 0세트면 안내 한 줄, 1세트 이상이면 "누적 N세트"를 보여줌(2026-09-19).
   **원형 타이머** (2026-09-19 추가): 시간이 줄어드는 게 눈에 보이도록, 남은 시간을 부채꼴로 보여주는 원형 타이머를 화면1 가운데에 둔다. 원 한 바퀴 = 한 세트 30분(1분 = 12°). 12시 방향 바로 옆에 휴식 조각(5분, 60°), 그 뒤에 집중 조각(25분, 300°)을 두고, 시간이 갈수록 부채꼴이 12시 쪽으로 줄어든다. 집중 조각이 먼저 다 사라지고, 휴식 조각까지 사라지면 세트 완료. 휴식 조각이 처음부터 원 안에 보여서 "휴식까지 마쳐야 한 세트"가 그림으로 전달된다. 집중과 휴식 조각은 다른 색으로 나누고, 원 아래에 지금 단계의 남은 시간을 작은 숫자(예: 12:30)로 함께 보여준다.
   **세트 동안 화면 켜 두기** (2026-09-19 추가): 세트를 시작하면 집중과 휴식이 끝날 때까지 화면이 자동으로 꺼지지 않게 한다. 세트 완료, "그만하기", 대기 상태에서는 원래대로 꺼질 수 있게 풀어 준다. 휴대폰 화면은 보통 1분 안에 자동으로 꺼져서, 이게 없으면 휴식으로 넘어갈 때 소리가 나지 않아 "휴식까지 마쳐야 별이 뜬다"는 차별점이 작동하지 않는다("한 번 써 보는 순서" 2번 막힘).
   - 다른 앱이나 탭으로 갔다가 돌아오면 화면 켜 두기가 풀리므로, 세트 중에 돌아오면 다시 켠다.
   - 사용자가 전원 버튼으로 직접 화면을 끄면 막지 않는다. 이때는 소리가 나지 않는다.
   - 화면 켜 두기를 지원하지 않는 오래된 브라우저에서는 원래대로 화면이 꺼질 수 있다. 따로 안내 화면은 만들지 않는다.
   "휴식까지 마쳐야 별이 뜬다"는 차별점을 직접 구현하는 기능이라 타협 불가 1순위.

2. **밤하늘 화면** — 화면2
   세트를 마치면 자동으로 이동해 새 별이 뜨는 모습을 보여줌. 작은별 10개가 모이면 중간별, 중간별 10개가 큰별, 큰별 10개가 대왕별로 합쳐짐. 누적 세트 수와 총 집중 시간(끝까지 마친 세트 × 25분)을 보여주고, "다음 세트 시작"으로 바로 다음 세트를 이어감. 0세트일 때는 빈 밤하늘과 "첫 세트를 마치면 별이 떠요"를 보여줌.
   **세트 진행 중·다시 열었을 때** (2026-09-19 추가): 세트가 진행 중일 때 밤하늘 탭으로 오면 "다음 세트 시작" 대신 "집중 중 · 12:30 남음"(휴식 중이면 "휴식 중 · 04:30 남음") 버튼을 보여주고, 누르면 진행 중인 화면1로 돌아간다. 자리를 비운 사이 세트가 끝났으면 다시 열 때 화면2로 들어와 별똥별이 떨어지는 모습을 보여준다.
   **움직임** (2026-09-19 추가): 별이 은은하게 반짝이고, 세트를 마치고 넘어오면 별똥별이 떨어져 새 별 자리에 박히며, 10·100·1000번째 세트에서는 별 10개가 빨려 들어가듯 모여 한 단계 큰 별로 커진다. 별이 정적이면 재미없다는 우려를 풀기 위한 것. 휴대폰의 "동작 줄이기" 설정이 켜져 있으면 움직임을 줄인다.
   가장 위험한 가정("별로 쌓여 보이면 반복한다")을 검증하는 화면.

3. **이미지 카드 사진첩 저장** — 화면3
   스토리 비율(9:16, 1080×1920px) 카드에 밤하늘, 누적 세트 수, 총 집중 시간, "별도로"를 넣음. "사진첩에 저장"을 누르면 공유 시트(Web Share)를 열고, 공유 시트가 없는 브라우저에서는 이미지를 길게 눌러 저장하라고 안내함. 0세트일 때는 "카드 만들기"를 누를 수 없음.
   세 기능 중 우선순위는 가장 낮음. 일정이 밀리면 이 기능부터 줄인다: 사진첩 저장 대신 카드를 화면에 띄우고 "화면을 캡처해 저장하세요"라고 안내한다(2026-09-19 결정). 이 경우 카드 저장 이벤트는 안내를 띄운 것까지만 기록한다.

**측정을 위한 최소 구현 조건** (기능이 아니라 위 3가지를 측정할 수 있게 만드는 전제, 2026-09-18 결정: 로그인 없이 B안)
- **기록 보관: 브라우저에만 저장.** 로그인·회원가입·서버·DB 없음. 누적 세트 수와 별 상태는 사용자 브라우저에 저장한다.
- **측정: 무료 분석 도구(GA4 등) 이벤트.** 분석 도구가 방문자마다 익명 ID를 자동으로 붙인다. 보내는 이벤트 4개:

  | 이벤트 | 언제 | 같이 보낼 값 |
  |---|---|---|
  | 세트 시작 | 화면1 "시작" 또는 화면2 "다음 세트 시작" | 어디서 눌렀는지(타이머/밤하늘) |
  | 세트 완료 | 휴식 5분이 끝났을 때 | 누적 세트 수 |
  | 그만하기 | 확인 창에서 "그만하기"를 눌렀을 때 | 집중 중이었는지 휴식 중이었는지, 시작 후 지난 시간 |
  | 카드 저장 | 공유 시트를 열고 취소하지 않았을 때, 또는 "길게 눌러 저장" 안내를 띄웠을 때 | 저장 방법(공유 시트/길게 누르기 안내) |

  - 카드 저장은 공유 시트에서 사진첩 저장을 골랐는지, 다른 앱으로 보냈는지까지는 알 수 없다. "길게 눌러 저장" 경로는 안내를 띄운 것까지만 알 수 있다.
- **테스터 개인 링크.** 테스터마다 `…/?t=07`처럼 번호가 붙은 링크를 나눠 준다. 첫 방문 때 번호를 브라우저에 저장하고 모든 이벤트에 붙여서, 로그인 없이도 누가 몇 세트를 했는지 알 수 있게 한다. 인터뷰할 때 그 사람의 기록과 맞춰 본다.
- **테스터 안내.** 기록을 분석 도구로 모은다는 점을 테스트 시작 전에 알린다.
- 분석 도구의 기본 보고서는 반영이 하루 정도 늦을 수 있어서, 테스트 기간에는 실시간 보고서로 확인한다.

**시연 모드** (2026-09-19 결정: 넣음)
- 한 세트가 30분이라 발표 시연과 완료 기준 테스트를 30분씩 기다리며 할 수 없고, 1라운드 안에는 큰별·대왕별이 나올 수 없다.
- `…/?demo=1` 링크로 들어오면 세트를 짧게(집중 1분 + 휴식 12초, 실제와 같은 5:1 비율이라 원형 타이머가 실제와 같게 나뉨) 돌리고, 누적 세트 수를 원하는 값(예: 9, 23, 150, 1000)으로 바꿔 볼 수 있게 한다. 9로 두고 한 세트를 마치면 10세트째에 별이 합쳐지는 순간을 시연할 수 있다. 세트 길이와 예시 값은 만들면서 바꿀 수 있다.
- 시연 모드의 기록은 실제 기록과 따로 저장하고, 분석 도구 이벤트도 보내지 않는다. 세트 길이를 고정한 이유(별의 무게가 모두 같아야 함)와 부딪히지 않게 하기 위해서다.

## 제외 — 이번 라운드에서 아예 만들지 않는 것 (Won't)

- 로그인·회원가입·서버·DB — 이번 교육과정에서 다루지 않음(2026-09-18). 기록은 브라우저에만 저장
- 일시정지 — "멈추면 인정 안 함" 규칙과 어긋남
- 휴식 건너뛰기 버튼 — "휴식까지 마쳐야 별이 뜬다"는 차별점과 어긋남
- 친구·랭킹·소셜 피드 — 공유는 사진첩 저장까지만. SNS에는 사용자가 직접 올림
- SNS 직접 올리기 연동(인스타그램 등)
- 통계 화면(날짜별·주별 그래프) — 누적 세트 수와 총 집중 시간만 보여줌
- 기록 초기화·삭제 화면
- 네이티브 앱(iOS/안드로이드 스토어 배포)
- 결제

## 보류 — 2라운드 이후 후보

- **로그인 + 기기 간 동기화** — 로그인 없이 가면 다른 휴대폰·브라우저에서 밤하늘이 이어지지 않고, 브라우저 데이터를 지우면 별이 사라진다. 아이폰 사파리는 7일 넘게 방문하지 않은 사이트의 저장 데이터를 지울 수 있다(홈 화면에 추가한 경우는 예외). 과정 안(3일)에는 문제되지 않지만, 판정을 과정 뒤에 하기로 해서(2026-09-19) 판정 기간이 7일을 넘기면 아래 홈 화면 추가 안내를 먼저 검토
- **홈 화면에 추가 안내(PWA)** — 위 사파리 데이터 삭제를 피할 수 있어서, 판정 기간이 7일을 넘기면 로그인보다 먼저 검토. 주의: 아이폰에서 홈 화면에 추가한 앱은 사파리와 저장 공간이 따로라서, 사파리에서 쌓은 별과 테스터 번호가 옮겨 가지 않는다. 테스트를 시작할 때 바로 홈 화면에 추가하게 안내하고, 홈 화면 앱이 테스터 번호가 붙은 주소(`…/?t=07`)로 열리게 설정해야 한다
- **세트 길이 바꾸기, 4세트마다 긴 휴식(15~30분)** — 원래 뽀모도로 방식. 길이를 바꾸면 별의 무게가 달라지므로 별 계산 규칙을 함께 정해야 함
- **브라우저 알림** — 화면이 꺼져 있어도 세트가 끝났음을 알림. 알림 허용을 묻는 단계가 하나 더 생기고, 정해진 시각에 알리려면 알림을 보내는 서버가 필요함(아이폰은 홈 화면에 추가한 경우에만 동작). 1라운드는 "세트 동안 화면 켜 두기"로 대신함(2026-09-19)
- **오늘·이번 주 기록 보기** — 누적 말고 기간별 세트 수
- **카드 종류 늘리기** — 피드 비율(1:1), 카드 꾸미기
- **공부 주제별 별 색깔** — 무엇을 공부했는지 별에 남기기 (아이디어 단계)
- **친구와 같이 가꾸는 밤하늘** — 처음 차별점 후보로 나왔던 아이디어 (아이디어 단계)

## 질문 필요

- 판정: 테스터 인원·기간, 기준 숫자 (과정 뒤에 하는 것은 2026-09-19 결정)
- 판정 기간이 7일을 넘기면: 판정 전에 홈 화면 추가 안내를 넣을지 (위 "보류" 참고)
- 비교 기준: 핵심 가설이 "더 오래·자주 반복한다"인데 판정 지표는 별도로 안에서만 잰다. 테스터가 지금 쓰는 뽀모도로 타이머로 하루 몇 세트를 하는지 모집 때 물어볼지 (2026-09-19 PRD2 작성 중 발견)

> 2026-09-19. topic.md "타겟 사용자"(퇴근 후 자기계발을 하며 뽀모도로 타이머를 쓰는 직장인)가 위 "1라운드 포함" 기능만으로 처음부터 끝까지 한 번 쓴다고 가정. "제외" 기능은 쓰지 않음.

1. 별도로 주소를 열면 화면1(타이머)에 "25분 집중하고 5분 쉬면 밤하늘에 별이 떠요"가 나오고, "시작"을 누르면 집중 25분이 줄어들기 시작한다.
2. 공부하는 동안 휴대폰 화면이 자동으로 꺼져서, 25분이 끝나 휴식으로 넘어갈 때 소리가 나지 않아 쉴 때가 된 것을 알 수 없다 — 화면이 꺼져 있어도 알려 주는 기능이 필요하다 (막힘)
3. 30분이 지난 뒤 화면을 켜면 시작 시각 기준으로 다시 계산해 세트 완료로 인정하고, 화면2(밤하늘)에 작은별 1개와 누적 1세트, 총 집중 25분이 나온다.
4. "카드 만들기"를 누르면 화면3에 9:16 카드(밤하늘, 1세트, 25분, "별도로")가 나오고, "사진첩에 저장" → 공유 시트의 "이미지 저장"을 누르면 카드가 사진첩에 들어간다.
5. ←로 화면2에 돌아와 "다음 세트 시작"을 누르면 화면1에서 바로 다음 집중 25분이 시작된다.

- 2번 막힘 처리(2026-09-19): "세트 동안 화면 켜 두기"를 1라운드 포함 기능(1번 뽀모도로 타이머)에 넣었다. 세트 동안 화면이 꺼지지 않으므로 25분이 끝날 때 소리가 나고 휴식으로 넘어간 것을 알 수 있다. 브라우저 알림은 그대로 보류.
