# 넣으면 나온다 — 별도로

> 1라운드(MVP 제작 교육 과정, ~2026-11-05) 기준 초안 (2026-09-18)

한 줄 : 집중·휴식 한 세트를 마치면 → 내 밤하늘에 별이 뜨고, 세트가 쌓일수록 별이 커진다

- 입력 : 타이머 시작 탭 한 번 → 집중 25분 + 휴식 5분 한 세트를 멈추지 않고 완료 (도중에 "그만하기"를 누르면 그 세트는 인정하지 않음)
- 처리 : 완료한 세트 수를 쌓고, 작은별이 10개 모이면 중간별 1개로 합친다 — 같은 방식으로 중간별 10개 → 큰별, 큰별 10개 → 대왕별
- 출력 : 두 번째 화면(밤하늘)에 별똥별이 떨어져 새 별이 박히거나 별 10개가 모여 큰 별로 커지는 모습이 보이고(별들은 늘 은은하게 반짝임), 그 밤하늘을 스토리 비율(9:16) 이미지 카드(누적 세트 수, 총 집중 시간, 서비스 이름 "별도로" 포함)로 사진첩에 저장할 수 있다
- 모양 : 키우는 도구
