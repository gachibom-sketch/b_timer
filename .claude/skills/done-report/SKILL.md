# 기능 완료 보고

## 언제 쓰나

- "○○ 다 됐어" 라고 말하기 직전

## 무엇을 받나

- 끝낸 기능 이름
- 그 기능이 붙는 화면(화면1 타이머 · 화면2 밤하늘 · 화면3 카드 미리보기)

## 어떤 순서로 하나

- 넘겨받기로 한 것이 없으면 만들기 전에 먼저 묻는다.

1. 지금 연 폴더 맨 위의 PRD.md 에서 수용 기준 20개를 읽는다.
2. 이번 기능과 닿는 기준을 고른다.
3. 기준마다 할 일을 적는다.
4. 기준마다 통과하면 보이는 것을 적는다.

## 무엇을 내놓나

3열 표 하나로 답한다. 수용 기준 한 줄에 표 한 줄을 쓴다.

| 수용 기준 | 할 일 | 통과면 보이는 것 |
|---|---|---|

- 같은 폴더의 template.md 양식대로 내놓는다.

## 지킬 것

- 받은 파일에 없는 내용은 지어내지 않는다.
